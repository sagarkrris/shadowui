# Company Prep layout

Company Prep opens on a recommended practice round and the saved round map.
Recommendation favours a round marked Weak, then the first unpractised round;
when all rounds are practised, it offers the first round for further practice.
It does not represent a scheduled interview or a measured readiness assessment.

The section navigation separates practice questions, the prep brief, application
tracking, and progress/source information. Inactive sections stay mounted so
switching views preserves unfinished application drafts. Existing saved records,
round statuses, question sources and mock prompts retain their storage contracts.

Across focused workspaces, account, profile, help and session tools live under
More in the desktop header. The Home button returns to Today. On mobile the
existing Navigation & settings and Session actions controls remain available.
The InterviewIQ watermark is retained.

Canvas, Design Lab, DSA and Java Digest keep the approach examples in an
expandable disclosure, leaving the task controls visible first. Q&A uses the
same approach for its interview answer checklist. The explanations remain
available without changing their content or the user's saved practice data.
